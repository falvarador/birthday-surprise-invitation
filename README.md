# 👑 Magical Princess Birthday Surprise & Interactive Invitation

> **GitHub Repo Short Description (for the "About" section):**
> An interactive, animated fairy-tale birthday cake surprise and digital party invitation built with HTML5, Tailwind CSS, SVG animations, Canvas particles, and Tone.js.

---

## ✨ Overview

A magical, single-page interactive web application designed to surprise a special little princess on her birthday and invite friends and family to the royal celebration. Inspired by a custom fairy-tale castle cake and a soft pastel color palette, the app guides users through a 3-step interactive experience.

## 🎂 Key Features

* **Interactive SVG Castle Cake:** Custom-built vector illustration featuring a fairy princess with a magic wand, pearl spheres, golden butterflies, flickering castle candles, and an arched floral door.
* **3-Step Guided Surprise:**
  1. **Make a Wish:** Tap the glowing castle flags to blow out the birthday candles.
  2. **Unlock the Secret Door:** Watch the floral door with the birthday number swing open in 3D.
  3. **Royal Invitation Reveal:** Open the full invitation card with a live countdown timer and party details.
* **Magical Audio & Particle Effects:** Synthesized music-box melodies and chimes powered by **Tone.js**, paired with an HTML5 Canvas particle engine for golden stars, hearts, and fairy dust.
* **Live Customization & RSVP Wall:** Easily customize the birthday girl's name, age, date, time, venue, and surprise message directly from the UI, or leave birthday wishes on the interactive guest wall.

## 🚀 Quick Start

This project is completely self-contained in a single file (`index.html`) and requires no build tools or installation.

1. Clone or download this repository.
2. Open `index.html` directly in any modern web browser, or deploy it instantly via **GitHub Pages**, **Vercel**, or **Netlify**.
